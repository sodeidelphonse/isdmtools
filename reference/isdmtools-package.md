# A Reproducible R Framework for Spatial Data Resampling and Multisource Validation of Integrated Species Distribution Models

`isdmtools` provides a set of tools for preparing, analysing and
visualising spatial data for integrated species distribution models
(ISDMs). It been developed to assist users in preparing multisource
point-level spatial datasets for block cross-validation, analysing the
habitat suitability from the joint model predictions, with a focus on
Bayesian inference and visualising the results.

The package also provides a holistic view of model performance by
computing a comprehensive evaluation metrics, including ROC-based and
error-based weighted composite scores and performing posterior
predictive checks.
